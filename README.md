# Miyya plugin frontend

Readable Angular source for the merchant interface and storefront widget shipped with **Miyya - AI Shopping Assistant for WooCommerce**, version **1.10.3**.

This repository contains the plugin frontend only. The WordPress PHP plugin, hosted AI backend, billing server, administrative portal and their private repository history are not included. Runtime access to the hosted Miyya service is separate from building this frontend.

## Build from source

Angular 22 requires Node.js ^22.22.3, ^24.15.0, or >=26.0.0. This standalone source was tested using Node.js 24.16.0 and npm 11.13.0. `package.json` also records the project package-manager preference. Install dependencies from the lockfile, then build:

```sh
npm ci
npm run build
```

The default build is production and writes `dist/plugin-frontend/browser/`. Angular also writes third-party license notices under `dist/plugin-frontend/`; retain those notices when distributing the output.

For integration with the WordPress plugin, copy the generated `dist/plugin-frontend/` directory into the PHP plugin's `dist/plugin-frontend/` directory. The PHP plugin provides the `window.AIAssistantConfig` bootstrap configuration and authenticated WordPress API routes. Building does not require credentials or a live backend; connecting a real store does.

## Development and tests

```sh
npm start
npm test -- --watch=false
```

The development server opens on `http://localhost:4200`; its development API default is `http://localhost:8000`. Configure a local frontend environment for your own service when developing. Production defaults to `https://app.heymiyya.com`. Never put service secrets or private API keys into frontend source.

`npm ci`, builds and tests generate `src/build-info.ts` and `public/version.json` using the standalone `scripts/build-info.mjs`. No scripts or files from the private monorepo are needed. Build commit/timestamp metadata varies across checkouts, so the compiled bundle need not have identical byte hashes even when the application source is the same.

## Source releases

The `v1.10.3` tag identifies this frontend source release. Use versioned tags when matching a WordPress plugin release. Tests and unminified TypeScript, Angular templates, styles and required public assets are included.
